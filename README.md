# Wilson Lee Portfolio

Portfolio for engineering projects and photography.

## Files

- [`index.html`](index.html): Document layout, top pill switch, profile button, and profile modal dialog.
- [`styles.css`](styles.css): Solid background themes (`#004B00` for Engineering, `#000000` for Photography), off-kilter card transforms, and modal styles.
- [`app.js`](app.js): Section switching, card/video rendering, YouTube hover-autoplay, fullscreen control, and dialog logic.
- [`portfolio-data.js`](portfolio-data.js): Data file for profile, engineering projects, and photography items.

## Local Preview

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`.
